# Third-Party Packages

QuickDrop uses the following open-source packages from pub.dev:

- Flutter / Dart
- file_picker
- path_provider
- cryptography
- cryptography_flutter
- path
- archive
- url_launcher
- font_awesome_flutter
- test
- flutter_lints
- inno_bundle
- flutter_launcher_icons

QuickDrop bundles the Manrope font under the SIL Open Font License 1.1.
The full license is included at `assets/fonts/OFL.txt`.

The GitHub mark is provided by Font Awesome Free through
`font_awesome_flutter` under its included open-source licenses.

Check their respective pub.dev pages for full copyright and license details.
